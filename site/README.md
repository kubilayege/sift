# sift.lakebed.app

The sift landing page and installer, as a [Lakebed](https://lakebed.dev) capsule.

- `client/`: the page (Preact). `mock.tsx` is a static rendering of the review UI with an
  invented example change, so the page never shows real code.
- `server/`: `/install.sh` (the `curl | sh` installer, checksums baked in), `/download/<name>.tar.gz`
  (redirects to the GitHub release asset), `/download/SHA256SUMS`, `/version`.
- `shared/releases.ts`: generated by `publish.sh`; names, URLs, sizes and checksums.

Binaries live as GitHub releases on [kubilayege/sift](https://github.com/kubilayege/sift), because
Lakebed storage does not accept executables.

## Release

```sh
../scripts/release.sh     # build macOS (arm64, x86_64) and static Linux (arm64, x86_64) into ../release
./publish.sh              # GitHub release v<version> + regenerate shared/releases.ts + lakebed deploy
```

Bump `version` in `../Cargo.toml` first; publishing the same version again replaces its assets.
Linux builds need Docker. They cross-compile with cargo-zigbuild inside one native container.

## Develop

```sh
npx lakebed dev
```
